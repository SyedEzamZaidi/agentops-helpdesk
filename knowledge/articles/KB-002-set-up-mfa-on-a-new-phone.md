# KB-002: Set up MFA on a new phone

**Applies to:** Microsoft Authenticator on iOS and Android · **Audience:** All employees · **Last reviewed:** 04 Oct 2026

## Before you start
- Keep your **old phone** until the new one is working, if you still have it.
- If you have lost your old phone and cannot sign in at all, do not follow this article. Ask the IT helpdesk agent to reset your MFA; the request is verified and approved before the reset.

## Steps
1. Install **Microsoft Authenticator** on the new phone from the App Store or Google Play.
2. On a computer, go to **mysignins.microsoft.com/security-info** and sign in (approve the prompt on your old phone).
3. Select **Add sign-in method → Authenticator app → Next**.
4. On the new phone, open Authenticator, tap **+ → Work or school account → Scan QR code**, and scan the code shown on the computer.
5. Approve the test notification on the new phone.
6. Back on the security info page, set the new phone as your **default sign-in method**.
7. Remove the old phone from the list.

## If it does not work
- **QR code will not scan:** choose "Can't scan image?" and enter the code and URL manually.
- **No notifications on the new phone:** allow notifications for Authenticator in the phone settings.
- Still not working: raise a ticket with the helpdesk agent.
