# KB-001: Connect to VPN from home

**Applies to:** Company laptops (Windows) · **Audience:** All employees with VPN access · **Last reviewed:** 04 Oct 2026

## Before you start
- VPN access is granted per user. If you have never used VPN, request access first: tell the IT helpdesk agent "I need VPN access". Access is approved by your manager.
- You need a working internet connection and your company account with MFA set up.

## Steps
1. Connect your laptop to your home Wi-Fi or a wired network.
2. Open the **Company VPN** app from the Start menu.
3. Select the gateway **vpn.rabudzu.com** and click **Connect**.
4. Sign in with your company email address and password.
5. Approve the sign-in request in Microsoft Authenticator.
6. Wait for the status to show **Connected**. Internal sites and file shares are now available.

## If it does not work
- **"You are not authorised to use this gateway":** your account does not have VPN access yet. Request it through the helpdesk agent.
- **The app keeps reconnecting:** switch to a different network (for example a phone hotspot) to rule out a router problem, then restart the laptop.
- **MFA prompt never arrives:** see KB-002.
- Still not working: raise a ticket with the helpdesk agent and include the error message.
