# KB-004: Share a large file securely with a client

**Applies to:** OneDrive and SharePoint · **Audience:** All employees · **Last reviewed:** 04 Oct 2026

## Rules
- **Do not** attach confidential files to email or use personal file-sharing services.
- Share with **specific people only**. "Anyone with the link" is disabled for external sharing.
- Set an **expiry date** on external links.

## Steps
1. Upload the file to **OneDrive** (or the project's SharePoint library).
2. Right-click the file and select **Share**.
3. Open **Link settings** and choose **Specific people**.
4. Enter the client's email address.
5. Untick **Allow editing** unless the client needs to change the file.
6. Set an **expiry date** (default 30 days, maximum 90).
7. Click **Send**. The client receives a link and verifies their email address with a one-time code.

## Good to know
- Files up to **250 GB** can be shared this way.
- To stop access early, open **Manage access** on the file and remove the link.
- For highly confidential data (contracts, personal data), apply the **Confidential** sensitivity label before sharing.
